# stories/ — source prose for story-illustrator

Plain-text stories/audiobook chapters. Illustrate one with:

    studio storyboard stories/gurdjieff-ch1.txt --duration 1800 --aspect 16:9 \
        --style "painterly, muted, 1900s" --characters-root characters/
    studio visuals <run_id> --characters-root characters/
    # then narrate / clips / stitch / audio / voice / save as usual
