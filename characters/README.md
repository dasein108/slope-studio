# characters/ — character reference library (story-illustrator)

One subfolder per character:

```
characters/
  gurdjieff/
    ref0.jpg          # 2-8 reference images: face visible, single subject
    ref1.png          # names don't matter; files starting with "_" are ignored
    _portrait.png     # (generated by --portrait; becomes the sole anchor)
    card.json         # (generated) locked descriptor + canonical anchor
  ouspensky/
    ...
```

Build/rebuild a card after adding images:

    studio characters-build gurdjieff
    studio characters-build gurdjieff --portrait --style "painterly, 1900s oil"

No pictures for a character? Lock a TEXT-DERIVED card instead — the whole story is
analyzed once for their physical traits (gaps filled with committed specifics), so
their shape stays constant across scenes:

    studio characters-extract "the abbot" stories/ch1.txt
    # or automatic for all unknown recurring characters: studio storyboard --discover (default)

`card.json` is yours to curate: fix the descriptor, add story spellings to
`aliases` ("G.", "Georgi Ivanovich"). See the story-illustrator skill.
