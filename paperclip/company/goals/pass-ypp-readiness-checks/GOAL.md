# Pass YPP readiness checks

Child goal under `Unlock Youtube monetization`.

Required checks:

- follow YouTube channel monetization policies
- channel is in a YPP-supported country/region
- no active Community Guidelines strikes
- Google Account has 2-Step Verification enabled
- YouTube advanced features access is enabled
- one active AdSense for YouTube account is linked or ready to set up in YouTube Studio
- content is original and authentic, not mass-produced or repetitive
